Setup Guide

Only the trip organizer needs to set up the sheet. Friends just open your Share Link.

1. Create a Google Sheet

Open sheets.new and name it after your trip.

2. Paste Apps Script

Click Extensions → Apps Script, replace all code in Code.gs with the copied script, and click Save.

3. Deploy as Web App

Click Deploy → New deployment → Select type: Web app → Execute as: Me → Who has access: Anyone → Click Deploy and copy the Web App URL.

4. Connect the Trip

Click the top-right ⚙️ icon → Add / Switch Trip. Paste the Web App URL and give the trip a clear name (this name will become the official Trip Name).

5. Configure Trip Settings

Go to the Trip Settings tab and fill in the important details before anyone starts adding expenses:

  • Trip Name & Dates
  • Home Currency (the currency you want to settle in)
  • Default Expense Currency
  • Participants — real names of everyone on the trip (comma separated)
  • Categories (optional)

Tip: Set correct names and currencies first. Renaming people later does not automatically update old expenses.

6. Share with Friends

Click the top-right ⚙️ icon → Share Trip Link and send the link to your friends. They can open it directly and start adding expenses.
